# IN3050 - Introduction to Artificial Intelligence and Machine Learning (2021-2022)

My solutions to the three mandatory assignments of IN3050 at the University of Oslo, as Jupyter notebooks
(Python, NumPy, Matplotlib). Each folder also has the notebook exported to PDF.

| Folder | Topic |
|---|---|
| `AI_Mandatory_1` | Traveling Salesman Problem on European cities: exhaustive search, hill climbing, genetic algorithm |
| `AI_Mandatory_2` | Supervised learning: linear and logistic classifiers, multi-class, multi-layer neural network |
| `AI_Mandatory_3` | Unsupervised learning: PCA and clustering |
